Nuestro proceso

Del cafetal a la taza

Explicamos de forma sencilla cómo cuidamos el café durante las diferentes etapas del proceso.

🌱

1. Cultivo

El café se cultiva aproximadamente a 1,200 metros sobre el nivel del mar. Trabajamos para mantener plantas saludables y frutos de buena calidad.

🍒

2. Cosecha

Seleccionamos los frutos que presentan las mejores condiciones de madurez para mantener un sabor uniforme.

☀️

3. Secado

El grano se seca de manera controlada para reducir la humedad antes del almacenamiento.

🔥

4. Tueste

Controlamos el tiempo y la temperatura para obtener un tueste medio y resaltar las características del café.
